# Classification Model - DecodeLabs Project 2

## 📌 Overview
This project is a basic Machine Learning classification model built using Python and Scikit-learn.  
The goal is to predict a target class based on demographic and statistical features.

---

## 📊 Dataset
The dataset contains multiple features such as:
- SEX
- AGE
- URBANISATION
- UNIT_MEASURE
- TIME_PERIOD

Target variable was created based on OBS_VALUE after preprocessing.

---

## ⚙️ Workflow
- Data Cleaning & Missing Values Handling  
- Feature Engineering  
- Encoding Categorical Variables  
- Train/Test Split  
- Model Training using Decision Tree Classifier  
- Model Evaluation (Accuracy, Precision, Recall, F1-score)

---

## ⚠️ Challenges
- Highly imbalanced dataset  
- Missing values in target variable  
- Categorical feature encoding issues  

---

## 🧠 Tools Used
Python | Pandas | Scikit-learn | Machine Learning

---

## 📈 Model Performance
Achieved good accuracy, but recall for minority class was low due to class imbalance.
